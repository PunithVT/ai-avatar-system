# Development / CI tooling. Kept separate from requirements.txt so the runtime
# image doesn't ship linters.
#
# ruff is PINNED deliberately. Its formatter is not stability-guaranteed
# across releases: with an unpinned `pip install ruff`, CI's
# `ruff format --check` could start failing on untouched code the day a new
# version ships, and local runs would disagree with CI. Bump this
# intentionally, then run `ruff format .` in the same commit.
ruff==0.15.15
