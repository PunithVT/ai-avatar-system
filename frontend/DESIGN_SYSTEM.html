PRINCIPLES

Five rules — read these first

1. Monochrome canvas

Default text is #0a0a0a on #fcfcfd. Secondary is gray-500. The brand primary-600 (#444CE7) is reserved for buttons, links, and one accent per page — never paint full surfaces with it.

2. Urbanist headlines, Inter body

All H1–H6 switch to Urbanist with letter-spacing: -0.015em. H1 is weight 400 (thin). H2/H3 are weight 500. Body and UI labels stay on Inter.

3. JetBrains Mono is for labels, not code

The 11-px uppercase EYEBROW LABELS above section titles are JetBrains Mono · 500, gray-400, letter-spacing 0.15em. Use it consistently — it's the most recognisable HireAI signature.

4. No gradients. Ever.

The brand is flat, monochrome, deliberate. Hero panels use solid #0a0a0a. Cards use rgba(0,0,0,0.02) tint. If you find yourself reaching for a gradient, pick a slightly darker swatch instead.

5. Rounded surfaces (16–20px)

Standard card radius is 16px (rounded-xl). Hero / featured panels use 20–24px (rounded-2xl). Buttons and inputs use 8px. Avatars and pill-badges are fully rounded.

6. One italic accent, sparingly

For a soft typographic accent inside a headline, switch one word to Playfair Display italic. Use it once per page max — never in body copy.

DO & DON'T

Quick guardrails

DO

  • ✓ Use #0a0a0a for hero panels and footer; never a colored gradient
  • ✓ Pair Urbanist headlines with Inter body and JetBrains Mono micro-labels
  • ✓ Keep cards on a 2% black tint with 16-20 px radius
  • ✓ Use primary-600 sparingly — buttons, links, one accent per page
  • ✓ Use Playfair Display italic on one word per headline, max

DON'T

  • ✗ Never use gradients (neither colored nor monochrome)
  • ✗ Never paint surfaces with primary-600 — it's an accent, not a background
  • ✗ Don't use heavy shadows; default is shadow-xs
  • ✗ Don't combine Urbanist + body weight — bodies stay on Inter
  • ✗ Don't use Playfair Display in UI controls, body copy, or buttons
